「送信開始」は新しい session を発行する（走行中なら新 session で止まり、動きの制限は設定の初期値に戻る）。 位置モード: スティックを離せば（不感帯の内側なら）0 を送る。速度モード: 離せばその姿勢で止まる（「離すと中央へ戻る」なら戻る速さで 0 へ）。「中央へ」で指令姿勢を 0 に。 スティックが見えなくなったり割り当てた軸が機器に無いときは最後の値のまま frame_seq を止める（速度モードの積分も止まる。サーバーが鮮度切れで減速停止する）。 ack が stale_session（別のクライアントが session を発行した・サーバー再起動）なら送信を止める。再開は「送信開始」。
