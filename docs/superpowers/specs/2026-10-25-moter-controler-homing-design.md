# moter-controler: 系統選択・センサー表示・原点復帰・定位置移動（設計）

作成 2026-10-25。encoder-tester の実測（`encoder-tester/docs/results_20261025.md`）を踏まえて、`moter-controler/` に機能を足す。

## 目的と背景

H3 の 3 軸を、同じハード（CoreS3 SE + DIN Base + MD13S + リレー 2 + レベル変換）を 3 台並べて独立制御する。各個体は自分がどの系統（ケーブル表記 #1〜#3）を担当するかを知り、電源投入後に**下限へ当てて原点を取り、中立（水平・中央）へ移動**できる必要がある。フィードバックセンサーはインクリメンタル（モーター軸 400 count/rev、4 逓倍）なので、起動時の絶対位置は分からない。

現状の moter-controler はタッチ UI とシリアルで電源リレー・ブレーキ・速度を手で操作するだけで、センサーを読んでいない。

## ゴール

- 系統 #1〜#3 の選択。選択と系統ごとのパラメータを NVS に保存し、起動時に前回の選択を復元する。
- センサー値の表示（カウント、count/s、A/B レベル、原点の有無、校正の有無）。
- 「下限へ」「上限へ」「中立へ」「校正」の自動移動。
- 既存の手動操作（電源、ブレーキ、速度 ±1/±10、停止、非常停止）とシリアルコマンドは残す。

## 非ゴール

- PC からの位置指令への追従制御、3 軸の同期。
- 電流監視（VIOUT）。
- DIN 12V と USB 同時接続時の電源断（GitHub Issue #1）の対策。
- 着座荷重での動作確認。

## 失敗とみなすもの

- 自動移動が止まらない（カウントが止まっても PWM が出続ける、タイムアウトが無い）。
- STOP / 非常停止 が自動移動を即座に止められない。
- 未校正の系統で中立へ移動してしまう。
- 系統を間違えて保存値を上書きする（選択の切り替えが運転中に起きる）。

## ブレーキの意味（既存コードとの対応）

ブレーキは 24V 通電で解除、無通電で作動（実測）。moter-controler の `brake_on == true` は GPIO1 HIGH ＝ リレー ON ＝ 24V 通電 ＝ **解除**である。encoder-tester の `BRAKE_RELEASE_LEVEL = 1` と同じ。この文書で「ブレーキ解除」は `brake_on == true`、「ブレーキ作動」は `brake_on == false` を指す。`estop()` が GPIO1 を落とすのは「ブレーキを掛ける」方向で、整合する。
UI のラベルは「ブレーキ 入/切」から「ブレーキ 解除/作動」に直す（こちらの判断。入/切では読み手が逆に取る）。

## 用語と座標

- **P 端**: 速度 +（DIR Low）へ動かして当たる端。#1・#2 では下限（沈み切り）、#3 では右端。
- **N 端**: 速度 − へ動かして当たる端。#1・#2 では上限、#3 では左端。
- **原点**: P 端。ここをカウント 0 とする。カウントは N 端へ向かって増える（ENCODER_SIGN=+1 のまま、速度 − でカウント増）。
- **ストローク**: P 端から N 端までのカウント。
- **中立**: 原点からのカウント。既定はストロークの半分。
- UI のボタン名は #1・#2 で「下限 / 上限」、#3 で「右端 / 左端」。内部は P 端 / N 端。
- **#3（後部ヨー）も同じ方式で対象に含める**（操作者の決定）。両端に機械的な止まりがあることを前提にする。初回の校正は、止まりに当たることを目で確認しながら行う。#3 のストロークは未測定なので、移動量上限と時間上限は #1 の実測より余裕を持たせる（下の定数）。

## 系統プロファイル（NVS）

NVS 名前空間 `h3`。

| キー | 型 | 内容 |
| --- | --- | --- |
| `motor` | u8 | 選択中の系統 1〜3 |
| `m{n}_stroke` | i32 | ストローク（カウント）。未校正は 0 |
| `m{n}_neutral` | i32 | 中立（原点からのカウント）。未校正は 0。校正時にストローク/2 を書く |
| `m{n}_cal` | u8 | 1 なら校正済み |
| `m{n}_sign` | i8 | 計数の符号。+1 か −1。校正の P 端行程で自動判定して書く（下記） |

- 起動時に `motor` を読み、無ければ 1。選択系統のプロファイルを読む。
- 系統の切り替えは、電源リレー OFF かつ自動移動していないときだけ受け付ける。切り替えたら原点は無効に戻す。
- **原点の有効期間**（こちらの判断）: センサーの 5V は主電源リレーの下流ではない（リレー OFF の DISARMED でも A/B が定まった値を出していた）ので、MCU が動いている限り計数は続くとみなし、主電源リレーの OFF/ON では原点を保つ。無効にするのは、系統の切り替え、MCU の再起動、非常停止（ブレーキ解除が制御外で落ち、機構が動き得る）の 3 つ。無効になったら「中立へ」は再び拒否し、画面に「原点なし」を出す。
- 校正済みでない系統を選んでいるときは、画面に「未校正 / CAL を押す」と出し、「中立へ」は受け付けない。「P 端へ」「N 端へ（原点があれば）」「校正」は受け付ける。N 端へ到達したとき、校正済みなら保存値と比較して ±5 % 以上違えば警告、未校正なら実測ストロークを表示するだけで保存しない（保存は校正の完了時だけ）。
- **計数の符号**: #1 では速度 − でカウント増（ENCODER_SIGN=+1）だが、#2・#3 はモーター軸の回転方向が逆になり得る。校正の P 端行程で、速度 + で動かしたときにカウントが**減る**なら `m{n}_sign = +1`、**増える**なら `−1` と判定して保存し、以後その系統では符号を掛けて「N 端へ向かって増える」座標にそろえる。判定には 1 回転分（400 カウント）以上の移動を要する。校正前の系統では保存済みの符号が無ければ +1 を仮に使い、P 端へ到達した時点で同じ判定をして一時的に採用する（保存は校正時）。
- 書き込みは校正の完了時だけ。途中で止まったら書かない。

## 自動移動

すべて、電源リレー ON、ブレーキ解除、速度 0（手動指令が無い）のときだけ開始できる。開始後に電源 OFF・ブレーキ作動・STOP・非常停止・手動速度操作のどれかが来たら即中止（PWM 0）。中止・完了・失敗はシリアルに 1 行出し、画面の状態欄に出す。

### 共通の守り

- **無パルス停止**: PWM を出しているのに、カウントが `STALL_MS`（既定 200 ms）変わらなければ止める。端当てでは「到達」、それ以外では「失敗: stall」。開始直後は `START_GRACE_MS`（既定 300 ms）だけ待つ。
- **遅すぎ停止**（実機の受け入れ 7 で追加）: 片相断線では計数が止まらず 65 count/s 程度で進み続けるため、無パルスだけでは検出できない。`STALL_MS` ごとの速度窓が `MIN_COUNT_RATE`（既定 150 count/s）未満なら無パルスと同じ扱いにする。端当てで開始から `ARRIVAL_MIN_TRAVEL` 以上動いていれば「到達」、動いていなければ「失敗: slow」。
- **移動量上限**: 1 回の自動移動で `MAX_TRAVEL`（既定 12000 カウント。#1 のストロークより十分大きく、#3 の未測定ぶんの余裕を含む）を超えたら失敗で止める。
- **時間上限**: 1 回の自動移動は `MOVE_TIMEOUT_MS`（既定 45 s）で失敗で止める。
- **Duty 上限**: 自動移動の Duty は `AUTO_DUTY_MAX`（既定 15）を超えない。端当ては `HOME_DUTY`（既定 10）。校正中の N 端行程は保存ストロークを信じず常に `HOME_DUTY`（再校正で保存値が実際より大きい場合に 15 % で端に当たらないため）。
- **端当ての退避**（実機で追加）: 端当て（下限へ・上限へ・校正の両端）で、開始から `ARRIVAL_MIN_TRAVEL` 未満しか動かずに無パルス／遅すぎになったときは、すぐ失敗にせず反対方向へ `RETREAT_COUNTS`（600）退避してから改めて端へ向かう。既に端に居る状態で開始した場合と、ブレーキやセンサーの異常で動けない場合を区別するため。退避でも止まれば失敗（stall / slow）。退避は行程ごとに 1 回だけ。
- **手動速度の守り**（実機で追加）: 手動速度（±1 / ±10、S）の出力中も、無パルス停止と遅すぎ停止を同じ窓で適用し、出力を 0 にラッチして速度指令を 0 に戻す。センサーのケーブルが抜けたまま手動で動かし続けないため。|速度| が MANUAL_GUARD_MIN_DUTY（= NEUTRAL_DUTY_MIN、7 %）未満は監視しない（機構が動かないことがあり、+1 で徐々に上げる操作を止めてしまうため。実機で確認）。遅すぎ停止は |速度| が HOME_DUTY 以上のときだけ。
- **入力の鮮度**: 制御タスクは UI ループからの入力更新が 200 ms 途絶えたら主電源 OFF・手動 0 として扱い、出力を 0 にする（UI ループ停止時の守り）。

### P 端へ（原点復帰）

1. 速度 + を `HOME_DUTY` で出す。原点が既に分かっていて端まで 400 カウント以上あるときは `AUTO_DUTY_MAX` で近づき、残り 400 カウントで `HOME_DUTY` に落とす（こちらの判断。10 % で全ストロークを走ると 10 秒以上かかる）。
2. 無パルス停止で「到達」。PWM 0。
3. この位置を原点（カウント 0）にする。原点有効。
4. ストロークが分かっている場合、到達前のカウントと矛盾（到達位置が予想から ±10 % 以上ずれる）があれば警告を出す。

### N 端へ

1. 原点が無ければ受け付けない（校正中は除く）。
2. 速度 − で同様に近づき、無パルス停止で到達。
3. 到達位置のカウント＝実測ストローク。校正中ならプロファイルへ保存（ストローク、中立＝ストローク/2、校正済み）。校正外なら保存値と比較し、±5 % 以上違えば警告。

### 中立へ

1. 原点が無い、または未校正なら受け付けない。
2. 目標 = 中立カウント。比例制御: `duty = clamp(Kp × 誤差, NEUTRAL_DUTY_MIN, AUTO_DUTY_MAX)`、向きは誤差の符号。既定 Kp = 1 % / 100 カウント、`NEUTRAL_DUTY_MIN` = 7（7 % で動くことを実測済み）。
3. 誤差が `NEUTRAL_BAND`（既定 ±10 カウント）に入ったら PWM 0。入ったまま 200 ms 続けば「到達」。惰性で出たら再度動かす。反転は既存の `writeMotor` が PWM 0 → 5 ms → DIR 切替をする。
4. 到達後の保持はしない（PWM 0、ブレーキは操作者が入れる）。沈む側へ流れることは画面のカウントで見える。

### 校正

「P 端へ」→ 原点 → 「N 端へ」→ 保存 → 「中立へ」を続けて行う。途中で中止・失敗したら保存しない。完了時に 1 回だけ NVS に書く。

## センサー読み取り

- GPIO17 = A（白）、GPIO18 = B（緑）。内部プル無し。
- espressif32 6.12（ESP-IDF 4.4）の `driver/pcnt.h`。ユニット 0、チャネル 0 = A エッジ / B レベル、チャネル 1 = B エッジ / A レベル、エッジとレベルの組み合わせで 4 逓倍（encoder-tester と同じ遷移表）。カウンタは 16 bit なので、±20000 の H/L リミットのイベントで ISR が int64 に積む。
- 制御は専用タスク（5 ms 周期、優先度は UI より高い）で行う。カウント読み出し、count/s（100 ms 窓）、自動移動の状態機械、PWM 出力をここで回す。loop() は UI・シリアル・描画だけ。共有値は critical section でコピーする。
- 表示は、原点基準のカウント（原点無しなら生の累積値に「原点なし」を添える）、count/s、A/B レベル（digitalRead の 1 点）、原点の有無、校正の有無、ストローク、中立。

## 画面（320×240、1 ページ）

上から順に。既存の配色（オレンジ系）を使う。

1. ヘッダー: 「#1」「#2」「#3」の切り替え（タップで次へ。電源 OFF かつ停止中だけ有効）、右に状態（停止 / 待機 / 運転 / 下限へ / 上限へ / 中立へ / 到達 / 中止 / 失敗 / 未校正）。
2. 電源 入/切、ブレーキ 入/切（既存）。
3. センサー行: カウント（大きめ）、count/s、A/B、原点・校正の印。
4. 速度 −10 / −1 / +1 / +10（既存）。
5. 自動移動: 「下限へ」「上限へ」「中立へ」「校正」（#3 は「右端へ」「左端へ」）。条件を満たさないボタンは灰色。
6. 停止 / 非常停止（既存。常に有効）。
7. フッター: DIR、電源ピン、ブレーキピンのレベル（既存）。

高さ配分は builder に任せる。速度の数字表示は小さくしてよい。

## シリアル

既存の `R` `B` `S` `X` `E` `?` `HELP` に加えて:

| コマンド | 動作 |
| --- | --- |
| `M 1|2|3` | 系統の選択（電源 OFF 時のみ） |
| `HOME` | P 端へ |
| `UPPER` | N 端へ |
| `NEUTRAL` | 中立へ |
| `CAL` | 校正 |
| `?` | 既存の行に加えて `ENC motor=1 count=... pos=... cps=... a= b= origin=0|1 cal=0|1 stroke=... neutral=... auto=idle|home|upper|neutral|cal state=...` を出す |

自動移動中は 500 ms ごとに `ENC` 行を出す。開始・到達・中止・失敗は `AUTO ...` 行を出す。

## builder に任せること

- 画面の高さ配分と文字の大きさ。
- 制御タスクと UI の共有の仕組み（critical section で構造体をコピーする形で十分）。
- PCNT の ISR とオーバーフロー処理の実装詳細。
- 既存コードの分割（main.cpp 1 ファイルのままでも、分けてもよい）。
- ホストで走るテスト。状態機械（自動移動）と比例制御の計算は GPIO に依存しない形にして、`tests/` にホストテストを置くことを推奨する。

## 受け入れ確認（実機）

1. 起動 → 画面に前回の系統と「未校正 / 校正済み」が出る。
2. #1 で電源 ON → ブレーキ解除 → 「下限へ」→ 10 % で下端に当たって止まり、カウント 0 になる。
3. 「上限へ」（原点があるので未校正でも可）→ 上端で止まり、カウントが 5500 前後と表示される。保存はされない。
4. 「校正」→ 下限 → 上限 → 中立 まで通り、電源を切って入れ直しても校正済みのまま。
5. 「中立へ」→ 水平付近（高さ 389 mm 前後）で止まる。到達後 1 分、カウントの流れを目視。
6. 自動移動中に 停止 / 非常停止 / 電源 OFF で即止まる。
7. センサーの線を 1 本外した状態で「下限へ」→ `START_GRACE_MS` 内に 1 パルスも無ければ即失敗で止まる（端当てとして記録されないこと。到達と区別する規則: 開始からの移動が 1 周分（400 カウント）未満で止まったら「失敗: stall」、それ以上動いてから止まったら「到達」。ただし既に端に居る状態から当て直す場合があるので、原点が有効で予想位置が端から 400 カウント以内なら移動量が少なくても到達とする）。
8. 非常停止のあと「中立へ」が拒否され、「下限へ」で原点を取り直せる。
9. #2・#3 でも 2〜5 が通る。#3 は「右端へ」「左端へ」の表記で、校正時に止まりに当たることを目視する。符号が #1 と逆なら自動判定で保存され、以後の座標が左端へ向かって増える。
