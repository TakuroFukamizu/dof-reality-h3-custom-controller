# 故障診断の経緯

症状: リレーが動かない。PC から制御基板の COM ポートが認識されない。LCD 無表示。

| 順 | 測定・確認 | 結果 | 判断 |
| --- | --- | --- | --- |
| 1 | 電源基板のリレー（HRS4H-S-DC12V）と AC/DC（IRM-10-12）を特定 | | 12V コイルのリレーを IRM-10-12 の 12V で駆動する構成と推定 |
| 2 | IRM-10-12 の +Vo / -Vo | 当初 0V と見えたが、再測定で約 12V | 電源モジュールは正常 |
| 3 | リレーコイル抵抗 | 398Ω | コイル正常（12V で約 30mA） |
| 4 | コイル両端の対 GND 電圧（待機時） | 両方 11.9V | 12V 供給は正常。ローサイド駆動なら待機 OFF で正常 |
| 5 | PC の USB 認識 | デバイスマネージャーに変化なし | USB の列挙自体が始まっていない |
| 6 | 制御基板 LED | STM32 ボードの LED 点灯、D3 点灯、D4 消灯、LCD 無表示 | マイコンの起動不良または電源異常を疑う |
| 7 | STM32 ボードの 3.3V | ほぼ正常 | |
| 8 | STM32 ボードの 5V | **2.9V** | 異常 |
| 9 | 電源基板の 5V 出力 | 5.0V | 電源基板側は正常 |
| 10 | 電源基板 5V 出力 ⇄ STM32 5V 端子の電位差 | **2.1V** | 5V 供給経路で大きな電圧降下 |
| 11 | 電源基板 GND ⇄ STM32 GND | 0.9mV | GND 経路は正常 |
| 12 | 基板写真から STM32F4 系 Black Pill 互換ボード、U3（3 端子部品）を確認 | | 次は 5V 経路の導通（電源基板 5V ⇄ STM32 左下 5V ⇄ 右上 5V）を予定していた |

ここで **原因分析を保留**し、2 週間後のイベントに向けて制御基板を別のマイコンに置き換える方針へ切り替えた。

## 置換に向けた調査（導通・写真）

| 確認 | 結果 |
| --- | --- |
| PB_1〜3 の接続先 | Protection Board #1〜3（当初 MD13S と誤認） |
| CYT_1〜3 の接続先 | MD13S #1〜3 |
| PB_4 / CYT_4 | NC |
| MD13S MA/MB | 黒 2P コネクタ → モーター |
| 8pin の Brake 2pin | K1〜K4 の接点 |
| DC_STOP1 緑 | 電源基板側 R1（15kΩ）→ Q1 → HRS4H。制御基板側 STM32 B10 直結 |
| Protection Board 裏面 | LX-DS1 E328148、U1 = ACS71240 |
| VIOUT の行き先 | U6（刻印 21 BRPI = ADS1015）に 4 系統集約、I²C で PB8/PB9 |
| Feedback Sensor 6pin | GND ×2、抵抗経由で U5（ADS1015）へ 1pin、+5V、STM32 直結 2pin |
| Feedback Sensor ケーブル | 黒 ×2 = GND、赤 = +5V、白・緑 = STM32 直結、1pin NC |
| 白・緑の STM32 ピン | M1: PA9/PA8、M2: PB3/PA15、M3: PB5/PB4、M4: PB7/PB6（TIM1〜4 CH2/CH1） |
| STM32 刻印 | STM32F401CCU6 |
| 白・緑の電圧（5V 給電、停止） | 緑 5V、白 約 0.1V |
| K1〜K4 コイル | 並列、制御基板 Q1 で一括駆動 |
| ブレーキ用 24V | Protection Board の 24V 入力側と導通、出力側とは非導通 |
| Protection Board の GND | 信号 GND とモーター電源 GND が導通 |
| ブレーキに 24V 供給 | モーターがスムーズに回転（無通電作動・通電解除） |

## 置換後に残った保留事項

- 5V 経路の 2.1V 降下の原因（コネクタ・パターン・保護素子・U3・STM32 ボード側の過負荷）。
- 元ファームウェアの USB 初期化、BOOT0、NRST の状態。ST-Link による非破壊的な確認は未実施。
