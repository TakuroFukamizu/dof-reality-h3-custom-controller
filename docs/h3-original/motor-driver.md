# モータードライバと Protection Board

各軸のモーター電力経路は次の順になる。

```text
別体 24V 電源 → Protection Board LX-DS1（ACS71240 電流センサ）→ MD13S 電源入力 → MA/MB → 黒 2P コネクタ → DC モーター
```

## Cytron MD13S

| 項目 | 仕様 |
| --- | --- |
| メーカー / 型番 | Cytron Technologies / MD13S |
| モーター電源 | DC 6〜30V |
| 連続電流 | 13A |
| ピーク電流 | 30A（最大 10 秒） |
| 制御方式 | PWM + DIR（sign-magnitude） |
| ロジック入力 | 3.3V / 5V 対応 |
| PWM 周波数 | 最大 20kHz |
| テストボタン | 側面の MA / MB。マイコンなしで動作確認できる |

### 端子

電源・モーター側（4 極ネジ端子、基板の向きにより左から）: `MB` `MA` `−` `+`

制御側（白コネクタ、CYT_n からの 4 線）:

| ピン | 機能 |
| --- | --- |
| GND | ロジック GND |
| NC | 未接続 |
| PWM | 速度 |
| DIR | 回転方向 |

### 真理値表

| PWM | DIR | 出力 |
| --- | --- | --- |
| Low | 任意 | MA Low、MB Low（停止） |
| High | Low | MA High、MB Low（A→B 方向） |
| High | High | MA Low、MB High（B→A 方向） |
| PWM 波形 | Low / High | それぞれの方向で速度制御 |

新しいマイコンからは PWM・DIR・共通 GND の 3 信号で制御できる。3.3V ロジックのまま直結でよい。
ただし起動・リセット中に PWM 入力が不定にならないよう、ハードウェア側でプルダウン等の安全な初期状態を用意する。

公式の故障診断手順では、上位基板からの制御コネクタを外し、MA/MB ボタンでモーターが回れば次にエンコーダや制御基板を疑う流れになっている。

## Protection Board LX-DS1

裏面シルク `LX-DS1 E328148`。DOF Reality オリジナル。公開回路図・仕様書は見つからなかった。
当初は「MD13S の電源を ON/OFF する SSR のような基板」と呼んでいたが、実態は **電流計測基板**で、ソフトウェアから電源を ON/OFF する入力は確認できていない。

| 部品 | 内容 | 根拠 |
| --- | --- | --- |
| U1 | **Allegro ACS71240** ホール効果式電流センサ | 刻印 |
| D1 | 大型ダイオード状部品。サージ・逆起電力保護の可能性 | 目視。当初 Q1 = MOSFET と誤認したが根拠不足 |
| C1 / C2 | チップコンデンサ | 目視 |
| J1 | 4pin。制御基板の PB_n へ | 導通 |
| J2 | 電力端子。24V 入力と MD13S への出力 | 導通 |

公式の電源故障診断では、24V 電源・MD13S・5KP24CA 保護ダイオードが故障候補として挙げられている。

### J1（PB_n）のピン

| ピン | 役割 | 新設計での扱い |
| --- | --- | --- |
| GND | 共通 GND。MD13S 向け電源 GND と導通 | GND |
| +24V | モーター電源系の電圧（入出力の方向は未確定） | **GPIO に接続しない**。監視するなら分圧 |
| VIOUT | ACS71240 のアナログ電流出力 | 分圧して ADC へ |
| +5V | 電流センサなどのロジック電源 | 5V を供給 |

### ACS71240

- 電流に比例したアナログ電圧を VIOUT に出力する。過電流検出の FAULT 出力も内蔵するが、LX-DS1 で使われているかは未確認。
- 電流への変換は `I = (VIOUT − V_ZERO) / S`。感度 S とゼロ電流時電圧 V_ZERO は型番末尾で異なり、**未確認**。無電流時の VIOUT を実測してゼロ点を記録し、既知負荷で校正する必要がある。
- 3.3V 版と 5V 版がある。5V 版なら VIOUT が 3.3V を超えるため、ESP32-S3 の ADC には分圧が必要。
- 出力負荷抵抗の条件（10kΩ 以上）があるため、分圧抵抗の値と ADC 入力特性を合わせて確認する。

### ブレーキ用 24V との関係

- 各軸のブレーキ用 24V は Protection Board の **24V 入力側**と導通し、出力側（MD13S 側）とは導通しない。
- したがって VIOUT は **ブレーキ電流を含まず**、MD13S への給電電流を測っていると推定される。センサーの挿入位置とブレーキ電流の戻り経路の最終確認は残っている。

## 元の制御基板での使われ方

4 枚の Protection Board の VIOUT は制御基板の U6（ADS1015）に集約され、I²C で STM32 が読んでいた（[制御基板](control-board.md)）。
元ファームウェアは PWM 指令値とエンコーダの実位置を比較しており、電流値も監視に使っていたと考えられる。

## 新設計への含意

- MD13S と Protection Board はそのまま流用する。電力配線は変更しない。
- Protection Board には ON/OFF 用の GPIO は不要。VIOUT を各 CoreS3 の ADC で直接読む（A 案）。制御が難しければ、電流監視を使わず大元の主電源リレーを非常停止ボタンで切る構成で代用する。ただし主電源遮断は電流監視の代替ではなく、独立した最終停止手段として扱う。
- ESP32-S3 内蔵 ADC は精度・ノイズで外付け ADC に劣る。ソフトウェアの電流監視を過電流保護の唯一の手段にしない。
