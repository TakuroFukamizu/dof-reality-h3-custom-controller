# 電源基板

H3 コントローラーユニット内の電源基板。制御基板へ 12V と 5V を供給し、別体の 24V モーター用電源への AC 給電を主電源リレーで開閉する。
**モーター用の 24V を作る電源と、12V・5V を供給するこの基板は別のブロック**である。

## 搭載部品

| 部品 | 型番・刻印 | 役割 | 根拠 |
| --- | --- | --- | --- |
| AC/DC 電源モジュール | MEAN WELL IRM-10-12 | AC100〜240V → DC12V、0.85A、10.2W、入出力絶縁、基板実装型 | 刻印 |
| 5V 出力 | （生成方法は未調査） | 制御基板の STM32・ロジック電源、センサー電源 | 実測 5.0V |
| 主電源リレー | HONGFA HRS4H-S-DC12V 系 | 接点で 24V モーター電源の AC 入力を開閉 | 刻印・導通 |
| R1 | 15kΩ（シルク 1502、実測約 15kΩ） | Q1 のベース／ゲート抵抗 | 実測 |
| Q1 | 小型 3 端子 SMD、刻印読み取り不能 | HRS4H コイルの駆動素子 | パターン追跡 |
| LED | 動作確認用と思われる | Q1 の隣 | 目視 |
| DC_STOP1 | 4pin コネクタ | 制御基板との接続 | 導通 |

### IRM-10-12 の端子

| 端子 | 役割 |
| --- | --- |
| AC/L | AC 入力ライン |
| AC/N | AC 入力ニュートラル |
| +Vo | DC12V 出力（+） |
| -Vo | DC12V 出力（−） |

過負荷・短絡保護を内蔵しており、負荷側の短絡で出力を周期停止する。測定時は AC/L・AC/N 側に触れないこと。

### HRS4H リレー

| 項目 | 値 |
| --- | --- |
| コイル定格 | DC12V |
| 接点定格 | 10A / 250VAC、10A / 30VDC |
| コイル抵抗 | 398Ω（実測） |
| コイル電流 | 12V ÷ 398Ω ≒ 30.2mA、約 0.36W |
| 接点形式 | A 型なら 4pin、C 型（1c）なら 5pin。実物の形式は未確認 |

待機状態でコイル両端ともに GND 基準 11.9V だった。ローサイド駆動であれば、駆動素子 OFF でコイル両端が 12V になるため、これは正常な待機状態。

## DC_STOP1（電源基板 ⇄ 制御基板）

| 線色 | 信号 | 方向 | 備考 |
| --- | --- | --- | --- |
| 黒 | GND | 共通 | |
| 赤 | +12V | 電源基板 → 制御基板 | K1〜K4 など 12V 系 |
| 緑 | 主電源リレー制御 | 制御基板 → 電源基板 | 24V 系電源への給電リレー |
| 青 | +5V | 電源基板 → 制御基板 | STM32・ロジック・センサー |

### 緑線（主電源リレー制御）の経路

```text
STM32F401 PB10 ── DC_STOP1 緑 ── R1 15kΩ ── Q1 ── HRS4H コイル（12V）
                                                      │
                                               接点で AC を開閉
                                                      ▼
                                           別体 24V モーター用電源
```

- 制御基板側は STM32 ボードの B10 に直結。STM32 の GPIO は 3.3V ロジックなので、緑線は **3.3V ロジックの制御信号**として扱える。
- R1 = 15kΩ なら、3.3V 印加時の電流は最大 0.22mA（NPN なら I_B ≒ (3.3−0.7)/15k ≒ 0.17mA）。ESP32-S3 の GPIO で駆動できる負荷。
- **未確定**: Active High / Low、Q1 が NPN か MOSFET か、GPIO 未接続（浮き）時にリレーが OFF を維持するか。R1 が 15kΩ のベース抵抗で 30mA のコイルを十分飽和駆動できるかは Q1 の特性次第。
- 確認方法: 電源 OFF で Q1 の 3 端子のうち GND・コイル・R1 につながる端子を特定する。1 端子 GND、1 端子コイル、1 端子 R1 なら典型的なローサイド駆動で、PB10 High でリレー ON の可能性が高い。

## 別体 24V モーター用電源

- HRS4H の接点を経て AC が供給される。各軸の Protection Board を通って MD13S の電源入力へ 24V が入る。
- 電源の型番・容量・出力コンデンサ容量は未調査。AC を遮断しても出力コンデンサの残留エネルギーでモーターが動く可能性がある点に注意。
- H3 の公開仕様では最大消費電力 750W。

## 新設計への含意

- 既存の電源基板と 24V 電源は流用する。主電源リレーは DC_STOP1 緑線を 3.3V GPIO で駆動できる見込み。
- 主電源は 3 軸共通なので、CoreS3 ×3 のうち 1 台の GPIO で直接駆動するのではなく、3 台の駆動許可と物理非常停止を集約するインターロックで扱う（[安全設計](../cores3-controller/safety.md)）。
- 既存 5V を CoreS3 の Grove 赤線（5V）と並列接続しない。CoreS3 への給電は USB 等の別経路とし、逆流を整理するまで既存 5V と結ばない。
