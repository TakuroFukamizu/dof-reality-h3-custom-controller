# モーターとフィードバックセンサー

## H3 の公開仕様

| 項目 | 値 |
| --- | --- |
| 自由度 | 3DOF（Pitch / Roll / Yaw＝後部トラクションロス） |
| 最大動作角 | 約 20° |
| 最大速度 | 50cm/s（86°/s） |
| 公称トルク | 25N·m |
| 最大搭載重量 | 200kg |
| 最大消費電力 | 750W |
| 入力電源 | AC100〜120V / 210〜240V、50/60Hz |

出典: DOF Reality の H3 製品ページと技術仕様資料。

公式のモーター識別資料では、2022〜2023 年の Hs 型、2023 年以降の Hk/Hr 型が区別され、いずれも **デジタルエンコーダと電磁ブレーキ**を備える。旧型にはアナログ位置センサーの例もある。
エンコーダ搭載機は起動時に可動限界まで動いて中央へ戻る自動キャリブレーションを行う。

## モーター構成

| モーター | 位置と動き（2026-10-25 実機確認） |
| --- | --- |
| M1（ケーブル表記 #1） | 正面から見て右手前（着座者から見て左）。positive（DIR Low）でシート右前が沈む、negative で上がる |
| M2（#2） | 正面から見て左。positive（DIR Low）でシート左前が沈む、negative で上がる |
| M3 | 後部ヨー機構。Traction Loss（未確認） |
| M4 | 基板上は実装。H3 では未使用 |

M1・M2 は moter-controler / encoder-tester で駆動して確認した。M3 は未確認。モーターの電力は MD13S の MA/MB から黒 2P コネクタで供給される。
モーター後端の黒いユニットに Feedback Sensor のケーブルが入る。ユニットに型番の刻印は見えない。
減速機構があり、**モーターは手では回せない**。エンコーダの検証には電動で動かす必要がある。

## 8pin コネクタ

モーターごとに 8pin コネクタが制御基板につながる。パネル表記で上側 6pin が Feedback Sensor、下側 2pin が Brake。

### Feedback Sensor（6pin、5 線使用）

| 線色 | 接続先（制御基板側） | 役割 | 確度 |
| --- | --- | --- | --- |
| 赤 | 電源基板の +5V | センサー電源 | 確定 |
| 黒 ① | GND | | 確定 |
| 黒 ② | GND | 2 本ある理由は不明 | 確定 |
| 白 | STM32 GPIO（TIMn_CH2） | エンコーダ 1 相（仮に A） | 高 |
| 緑 | STM32 GPIO（TIMn_CH1） | エンコーダ 1 相（仮に B） | 高 |
| （1pin） | ケーブル側 NC。基板側は抵抗を介して U5（ADS1015）へ | 旧型のアナログ位置センサー用と推定 | 高 |

白・緑の接続ピンは [制御基板](control-board.md) の表を参照。4 軸すべてが独立したタイマーの CH1/CH2 に対応しており、2 相インクリメンタルエンコーダと判断して設計を進めている。

### 実測電圧

5V を供給した停止状態で、GND 基準:

| 信号 | 電圧 |
| --- | --- |
| 赤 | 5V |
| 緑 | 5.0V（High） |
| 白 | 約 0.1V（Low） |

直交エンコーダは停止位置によって各相が High/Low になるので、この組み合わせ自体は正常。
**少なくとも緑線に 5V が現れるため、CoreS3（3.3V GPIO）へは直結できず、レベル変換が必要。**

### 未確定事項

- 出力段がプッシュプルかオープンコレクタか。
- 1 回転あたりのパルス数（PPR）、4 逓倍カウント、減速比、センサーがモーター軸と出力軸のどちらを計測しているか。
- 最大エッジ周波数、長い配線とレベル変換後の波形品質。
- 白・緑のどちらをメーカーが A/B と呼ぶか（ソフト上は白 = A、緑 = B と仮称し、符号は実測で決める）。

### 分解能の求め方

テスターでは測れない。CoreS3 の PCNT で 4 逓倍カウントを取り、既知の角度または回転数と対にして求める。

```text
counts_per_degree              = |ΔC| / θ_deg
counts_per_measured_shaft_rev  = |ΔC| × 360 / θ_deg     （測定した軸の 1 回転あたり、4 逓倍）
encoder_ppr                    = counts_per_rev / 4            （エンコーダ軸を直接観察した場合のみ）
                               = counts_per_rev / (4 × G)      （出力軸で測り、減速比 G が既知の場合）
```

- 位置制御に必要なのは、エンコーダ単体の PPR より「可動機構が何度動いたときに何カウント変化するか」。例えば出力軸 ±20° で ±840 カウントなら 42 count/degree。
- 可動端のある H3 機構を 1 回転させない。安全に 360° 回せる軸にだけ目視 1 回転モードを使う。
- 正逆 3〜5 回反復し、残留カウント（ノイズ、バックラッシュ、目印の読み誤差）を評価する。
- インクリメンタル方式なので電源投入時の絶対位置は分からない。原点復帰と可動範囲の制限は別途設計が必要。
