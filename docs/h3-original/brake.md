# ブレーキ

各モーターは電磁ブレーキを備え、8pin コネクタの下側 2pin（Brake）で制御基板につながる。

## 動作方式（実測で確定）

| 項目 | 内容 |
| --- | --- |
| 給電電圧 | DC 24V |
| 24V 通電時 | **ブレーキ解除**。モーターがスムーズに回転した |
| 無通電時 | **ブレーキ作動**（無励磁作動型） |

CoreS3 から追加リレーで 24V を供給する試験で確認した。ブレーキを掛けたままモーターを駆動していたことが、初期の試験で「PWM 50〜60 付近で急に端まで動く」挙動に関係していた可能性が高い。
その値を始動 PWM の目安として引き継がず、ブレーキ解除後の条件で取り直す。

## 原基板での駆動方法（実測で確定）

```text
STM32 GPIO（1 本、ピン番号未確認）
   └── 制御基板上の Q1 ── K1〜K4 のコイル（並列）
                              │
        K_n の NO 接点 ─────────┘
          │
          ├── 入力: 軸 n の Protection Board の 24V 入力側から分岐した 24V
          └── 出力: 軸 n の Brake 2pin
```

- **駆動指令は全軸一括**。元の基板は軸別のブレーキ指令を持たない。
- **給電経路は軸ごと**。各軸の 24V を対応するリレー接点で開閉する。
- 接点は NO（a 接点）。無通電時に導通なし。「NC」とした初期の記述は訂正済み。
- 以前「STM32 が K1〜K3 を個別に制御」としていた推定は誤り。

## 混同しやすい 2 つの Q1

| 系統 | 経路 | 開閉するもの |
| --- | --- | --- |
| モーター用 24V 電源の投入 | STM32 PB10 → DC_STOP1 緑 → **電源基板の R1/Q1** → HRS4H 主電源リレー | 別体 24V 電源への AC |
| ブレーキへの給電 | STM32 GPIO → **制御基板の Q1** → K1〜K4 コイル | 各軸の 24V ブレーキ給電 |

## 新設計への含意

- 新設計では軸ごとに独立したリレー駆動モジュールでブレーキを制御する。これは**元の仕様の再現ではなく新設計としての変更**。
- ソフト上は「ON/OFF」ではなく `brake_release`（解除指令）として扱う。解除状態を読み返すセンサーはないので、表示は「解除指令中」とし「解除済み」と断定しない。
- 通常停止ではモーターで減速・停止してからブレーキ給電を切る。非常停止時の動作順序は別途検証する。
- リレー接点にはコイル負荷の開閉になるので、フライバックダイオードや TVS などの接点保護が必要。単純なダイオードはブレーキ作動を遅らせる場合があるため、停止時間の要求と合わせて選ぶ。
- 初回のエンコーダ試験で、ブレーキ給電 OFF 直後にカウントが −260 変化した。切替時の電気ノイズ、実際の軸の動き、計数処理のいずれかを切り分け中（[進捗と未確定事項](../cores3-controller/progress-and-open-issues.md)）。
