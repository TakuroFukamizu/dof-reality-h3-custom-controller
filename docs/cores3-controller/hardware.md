# ハードウェア

## CoreS3 と DIN Base

| 構成 | Grove ポート | 備考 |
| --- | --- | --- |
| CoreS3（無印） | A / B / C | DIN Base が標準付属 |
| CoreS3 SE または Lite + DIN Base | A / B / C | **現在の実装は CoreS3 SE（K128-SE）**。`platformio.ini` の board は `m5stack-cores3`、PSRAM 8MB Quad |

- Port A は Core 本体側面の Grove。DIN Base が出すのは Port B と Port C。DIN Base は DIN レール固定に対応し、500mAh のバッテリーを内蔵する。
- ESP32-S3: 240MHz デュアルコア、USB CDC、2 インチ 320×240 タッチディスプレイ。GPIO は 3.3V、**5V 耐圧ではない**。
- 各 Grove ポートの赤線は 5V。黒 = GND、赤 = 5V、黄 = IO1、白 = IO2。
- M5Unified の `port_*_pin1` は「5V に近い端子」で、色では白側になる。コードの IO1 / IO2 は公式表（黄 / 白）に合わせている。

## GPIO 割当（現状）

`moter-controler/include/config.h` と `encoder-tester` の設定に基づく。

| ポート | 線色 | GPIO | 用途 | 状態 |
| --- | --- | --- | --- | --- |
| Port.A | 黄 | **G2** | 主電源リレー制御（リレーモジュールの IN） | 配線・動作確認済み |
| Port.A | 白 | **G1** | ブレーキ解除リレー制御（リレーモジュールの IN） | 配線・動作確認済み |
| Port.B | 黄 | **G9** | MD13S PWM | 動作確認済み |
| Port.B | 白 | **G8** | MD13S DIR | 動作確認済み |
| Port.C | 黄 | **G17** | エンコーダ A（センサー白）レベル変換後 | 配線済み、計数は検証中 |
| Port.C | 白 | **G18** | エンコーダ B（センサー緑）レベル変換後 | 配線済み、計数は検証中 |
| M-BUS 物理ピン 2 | — | **G10**（ADC） | Protection Board VIOUT（分圧後） | 予定。未配線 |
| M-BUS | — | 3V3 | レベルシフタの LV 電源 | 使用中 |

注意点:

- Port.B の赤（5V）は MD13S に接続しない。GND は共通にする。
- GPIO1 / GPIO2 は I²C に使われうるため、M5Unified の外部機器探索（`external_display_value`、`external_speaker_value`）を無効化し、起動時に I²C の High でリレーが入らないようにしている。
- GPIO9 は起動時のストラップ状態に注意が必要。PWM 入力には外部プルダウンを入れ、リレーモジュールの IN にもオンレベルと逆のプル抵抗（HIGH オンならプルダウン）を外付けする。
- 「M-BUS の 2 番ピン」と「GPIO2」は別物。M-BUS 2 番 = GPIO10。Base DIN の M5-Bus 表では 2 番が NC だが、これは Base DIN 自身がその端子を使っていないという意味で、CoreS3 と嵌合する接点からは G10 を引き出せる。はんだ付けする箇所から M-BUS 2 番への導通を電源 OFF で確認する。
- GPIO17 / 18 は ADC 入力に使えない。VIOUT を Port.C に割り当てることはできない。
- 1 軸あたり PWM / DIR / エンコーダ ×2 / ブレーキ / 主電源 / VIOUT の 7 信号が必要で、Grove 3 ポート（6 信号）では 1 本不足する。そのため VIOUT を M-BUS から引き出す。

## MD13S との接続

Grove ケーブルを MD13S の 4 線コネクタ用に加工する。

| MD13S | CoreS3 側 |
| --- | --- |
| GND | Port.B 黒 |
| NC | — |
| PWM | Port.B 黄 G9 |
| DIR | Port.B 白 G8 |

PWM 設定: 20kHz（MD13S の上限）、10bit、sign-magnitude。速度 0 で PWM Low（両出力 Low）。反転時は PWM を落とし 5ms 待ってから DIR を変える。`DIR_POSITIVE_LEVEL = 0`（正転 = DIR Low = MA High）。

## リレーモジュール（主電源・ブレーキ）

- GPIO はコイルを直接駆動せず、ロジック入力・駆動トランジスタ・保護ダイオードが実装された既製の 1ch リレーモジュールの IN に入れる。3.3V 入力対応であることを確認する。
- 現在の設定は `RELAY_ON_LEVEL = 1`（HIGH でオン）。リセット中に浮いてオンしないよう、IN にプルダウンを外付けする。
- 主電源リレー: G2 → モジュール → 既存電源基板の主電源リレー駆動（DC_STOP1 緑 → R1 15kΩ → Q1）。緑線は 3.3V ロジックで、元の STM32 が直接駆動していた実績がある。最終構成では 3 軸共通のインターロックに置き換える（[安全設計](safety.md)）。
- ブレーキリレー: G1 → モジュール → 接点で 24V を開閉 → Brake 2pin。24V はその軸の Protection Board の 24V 入力側から取る。接点はブレーキのコイル負荷を開閉するので、フライバックダイオードや TVS などの保護を定格確認後に追加する。
- リレーの接点定格が DC24V のブレーキ電流を開閉できることを確認する。ブレーキの消費電流は未測定。

## エンコーダ用レベルシフタ

Feedback Sensor の白・緑は 5V 系なので、CoreS3 へ入れる前に 3.3V へ変換する。

### 使用部品: 秋月電子 AE-LCNV4-MOSFET（BSS138、販売コード 113837）

HV 側・LV 側それぞれに 10kΩ プルアップを持つ双方向レベル変換。OE 配線は不要。

| AE-LCNV4-MOSFET | 接続先 |
| --- | --- |
| HV | センサーへ供給する +5V |
| LV | CoreS3 M-BUS の 3V3 |
| GND | CoreS3 GND、センサー黒 ×2、センサー用 5V 電源の GND |
| HV1 | センサー白 |
| LV1 | Port.C 黄 G17 |
| HV2 | センサー緑 |
| LV2 | Port.C 白 G18 |
| HV3 / LV3 / HV4 / LV4 | 未使用 |

```text
センサー白 ── HV1 [AE-LCNV4-MOSFET] LV1 ── Port.C 黄 / G17
センサー緑 ── HV2                     LV2 ── Port.C 白 / G18
センサー +5V ─ HV
CoreS3 3V3 ── LV
センサー GND ─ GND ─────────────────────── CoreS3 GND
```

- Grove の赤（5V）を LV に入れない。GPIO を HIGH にして電源代わりにしない。
- センサー用 5V は既存の電源基板 5V を継続使用し、Port.C の赤は未接続にして絶縁する。
- G17 / G18 は内部プルアップ・プルダウンなしの入力にする。プルアップはシフタ側にある。
- HV–GND、LV–GND に 0.1µF を基板近くに追加。信号線（HV1/2、LV1/2）にはコンデンサを付けない（10kΩ プルアップで立ち上がりが遅くなる）。
- 期待値: 変換前 白 約 0.1V / 緑 約 5V → 変換後 LV1 Low 0V 付近 / LV2 High 約 3.3V。LV に 5V 近くが出たら CoreS3 に接続せず配線を再確認する。
- レベル変換は絶縁ではない。GND 回り込み対策とは別。
- 低速で読めても最高速度でパルスを取りこぼさないことの保証にはならない。波形・計数の検証が必要。
- センサー断線時もプルアップで HIGH になるため、HIGH 表示だけで接続正常とは判定しない。

### 代替候補

| 部品 | 特徴 | 状況 |
| --- | --- | --- |
| 秋月 AE-TXS0104E-BO（TXS0104E） | 4ch 双方向、プッシュプル／オープンドレイン両対応。OE を 3.3V 側で HIGH にする必要あり（基板上に OE プルダウン 10kΩ） | 購入済み、交換評価用に保留 |
| Adafruit TXB0104（千石電商） | 4ch、プッシュプル向き。オープンドレインや強いプルアップには不向き | 候補 |
| 固定方向の 5V 耐圧入力バッファ（74LVC 系） | 自動方向判定の波形乱れを避けたい場合 | 候補 |

BSS138 で低速計数ができても速度を上げるとカウントが合わない場合は、原因を波形・ノイズ・ソフト設定に分けて調べる。TXS0104E への交換で必ず解決するとは扱わない。

## Protection Board VIOUT の分圧（予定）

VIOUT は ACS71240 のアナログ出力で、5V 版なら 3.3V を超える。デジタル用レベルシフタは使えず、抵抗分圧で ADC の範囲に収める。

| 構成 | 分圧比 | VIOUT 5V 時 |
| --- | --- | --- |
| 上 10kΩ / 下 10kΩ（推奨） | 0.5 | 2.5V |
| 上 20kΩ / 下 30kΩ | 0.6 | 3.0V |

```text
VIOUT ── 10kΩ ──┬── G10（ADC）
                10kΩ
                 │
                GND（Protection Board の GND と CoreS3 の GND を共通）
```

- ESP32-S3 Arduino の `ADC_11db` では測定範囲上限が約 3.1V。10k/10k なら上限に余裕がある。ソフトの分圧比も合わせる。
- ACS71240 の出力負荷条件（10kΩ 以上）と、ADC のサンプリング回路が要求する入力インピーダンスに注意する。ノイズが大きければバッファやフィルタを追加。
- 分圧だけでは電源投入順序による逆給電や過渡電圧を防げない。必要なら入力保護を追加。
- Protection Board の +24V は GPIO に接続しない。+5V と GND は電源系統として配線する。

## 配線・施工の方針

- ジャンパーワイヤの仮配線を本番に使わない。圧着済みケーブル、ロック付きコネクタ、ストレインリリーフを優先する。
- HY2.0-4P（Grove）は小信号用。モーター電流やブレーキ電流を流さない。
- 信号配線はモーターの電力線やリレーの負荷線と束ねない。レベルシフタは CoreS3 の近くに置き、LV1/LV2 から CoreS3 までを短くする。
- センサー・レベルシフタの細い GND 線をモーター電流の戻り経路にしない。
- CoreS3 の内蔵バッテリー（DIN Base 500mAh）で駆動許可を保持しない。主電源が失われたことを検知できる構成にする。
