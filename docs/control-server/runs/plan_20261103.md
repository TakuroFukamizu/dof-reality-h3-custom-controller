- 計測で `WARN`（`gap_max` > 2000 us、CONTROL_OVERRUN、`session@release` < 5000）→ その軸の大きい段に進まない
- 計測で `ABORTED` / `POST_MARGIN`（作動後に端の余裕を越えた）、`slide` が進む条件を超えた → 同じ段を繰り返さない
- 計測で ENCODER_FAULT（無パルス）→ エンコーダか機構の詰まりか区別できない。次の回の前に機構を見る
- ポートの対応が合わない・知らない装置がいる

### 6.1 USB が応答しない（Issue #11）

ハブの **上流** ケーブルを抜く → 約 10 s 待つ → 挿す → §1 でポートを取り直し、`$CFG` と `P1`〜`P3` を直す。MCU は再起動しないことが多い（基準が残る）。`boot` が変わっていれば校正し直す。

### 6.2 FAULT から戻す

- サーバー経由: 送信を止める → `curl -sX POST -H "$H" $URL/v1/fault/reset` → 数百 ms 後に `st`。`LOCAL_ESTOP` のときは先に画面で 1.5 s 押し続けて解除。
- 計測中（サーバー停止中）: `$PY $T --port ... --mac ... --axis N --config $CFG fault-reset`

### 6.3 ENCODER_FAULT の後（基準が消える）

道具を止める → サーバー起動 → `fault/reset` → 校正（**OK が要る**）→（計測専用ファームならそのまま）DISARM 確認 → サーバー停止 → `info` → 計測を再開。
量産ファームで ARM するならさらにサーバー再起動。
