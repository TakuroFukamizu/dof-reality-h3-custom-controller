## 決めたこと: HOLDING の間はブレーキで保持する（`V1_HOLD_BRAKE`、branch `hold-brake`）

操作者の判断。`?seatprearm=0`（飛行の開始まで ARM しない）は開始が約 3 秒遅れるので不可。START で待たずに解除すること。

- HOLDING の間は目標が動かない（SET_POSITION を目標に入れるのは ACTIVE だけ）。管理画面のセンター戻しも START → ACTIVE で動くので、HOLDING は止まっている前提でよい。
- 流れ（`moter-controler/include/v1_axis.h`、詳しくは [protocol.md](../protocol.md) の「HOLDING のブレーキ保持」）:
  1. HOLDING に入る（ARM の完了・センター戻しの到達）→ ブレーキ解除のまま **実測の静止** を待つ（|速度| ≤ 10 count/s かつ |誤差| ≤ 20 が 200 ms）。
  2. 作動指令。100 ms は位置ループで支える（`V1_HOLD_BRAKE_SUPPORT_MS`）。
  3. Duty 0（ループの状態を捨てる）。そのときの実位置を基準にし、基準から 20 count を超えてずれる（滑り）か、目標との差が 40 を超えたら（`V1_HOLD_BRAKE_MAX_ERR_COUNT`。サーバーの静止判定 `rest_error_count` 50・センターの幅 `center_tolerance_count` 50 より内側）、異常にはせず解除して位置制御へ戻る（その HOLDING の間は作動に戻らない）。
  4. START でその場で解除し、すぐ通常の位置制御。物理的に外れるまでの 150 ms（`V1_HOLD_BRAKE_RELEASE_GRACE_MS`、仮）は動き出しパルスと停止ブーストだけ出さない。
  5. DISARM・異常停止は従来どおり（ブレーキ作動）。
- 保持の幅はフリーズ版の 2/4 のまま。飛行中（ACTIVE）の動きはフリーズ版と同じ。
- 実装は Sonnet、レビューは Codex（4 回。327d89c → 7b5b48a: 静止を待ってから作動・解除直後のパルス抑止、bd7cf96: 滑りを基準位置から見る・支え 100 ms、5cf2f9d: 目標との差の上限 40）。ホストのテスト 4 構成とも失敗 0（8875 / 8875 / 8875 / 12034）。`-DV1_HOLD_BRAKE=0` で従来の動き。
