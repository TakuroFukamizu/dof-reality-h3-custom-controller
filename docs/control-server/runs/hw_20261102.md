## 00:10 の FAULT（変更前、kp 2 / duty_min 7）

START 時に #2 が中立の 240 count 下（2512 / 2753）にいて Duty 7〜8 % では 1 count も上がらず、roll を +1 まで倒して目標が離れ、誤差が 400 を超えて FOLLOWING_ERROR。#1 も目標 2778 に対して 2769 → 2758 と下がり、7 % で戻らなかった（不感帯 20 の中なので目立たない）。kp 2 では 9 % に達するのに誤差 450 が要り、その前に制限 400 で止まる。= この組み合わせでは自重に逆らう操作が必ず FAULT になる。

## 読み

- 位置ループの出力は kp 6 でも誤差 50 で 3 % にしかならず、実際の駆動は duty_min 9 % の下限が支配している。速度 600 count/s・Duty 20 % の範囲では追従誤差 50 前後で足りているが、制限を上げる（速度 1200 以上、gain 0.5 以上）と kp か FF の見直しが要る。
- #1 と #2 で自重のかかり方が違う（#1 は 0 % でほぼ保持、#2 は 9 % 必要）。片側だけ下がる現象の理由は機構側。
- 次: 速度 600 → 1200、加速度 2000 → 5000 を順に上げて同じ正弦波を流し、追従誤差と `acceleration_limited` の出方を見る。

ログ: サーバー `server_joy.log`、試験スクリプト `hw_test_kp6.py` と `hw_test_kp6.log`（セッションの scratchpad）。
