# 配線

この表は、動作確認済みの `moter-controler` と、今回のエンコーダ入力を合わせたもの。画面とログの `POWER ON CMD` / `BRAKE RELEASE CMD` は GPIO への指令であり、接点や電圧を測った結果ではない。

HY2.0-4P の色は、公式の並びとする。黒が GND、赤が 5V、黄が IO1、白が IO2。Port A は Core 本体側、Port B と Port C は DIN Base 側。

## 駆動

| 信号 | コネクタ | GPIO | 接続 | レベル |
| --- | --- | --- | --- | --- |
| 主電源リレー | Port A 黄 | G2 | リレーモジュールの IN | HIGH で給電指令 |
| ブレーキ解除リレー | Port A 白 | G1 | リレーモジュールの IN | HIGH で解除指令 |
| MD13S PWM | Port B 黄 | G9 | MD13S PWM | 20 kHz、10 bit。100% は 1023 |
| MD13S DIR | Port B 白 | G8 | MD13S DIR | 正方向は Low |
| 共通 GND | 黒 | GND | MD13S GND | 3.3 V ロジック |

Port B の 5V は MD13S に繋がない。GPIO はリレーのコイルではなく、モジュールの IN を駆動する。HIGH で入る回路には、リセット中の浮きで入らないように外部プルダウンを付ける。

ブレーキは、24V を供給すると解除、無通電で作動する。これは実測。ソフトの名前は `brake_release` で、`brake_on` とは呼ばない。

電力の経路は `24V 電源 → Protection Board → MD13S → モーター` のまま。G2 の先は `DC_STOP1 緑 → R1 15kΩ → 電源基板 Q1 → HRS4H`。この主リレーは、別体の 24V モーター電源への AC を入切する。AC を切っても 24V がすぐ消えるとは限らない。

G2 は 3 軸共通の AC 給電になり得る。このツールは 1 台の CoreS3 だけで使う。G2 に CoreS3 を並列に繋がない。試験しない軸は、物理的に動かない状態にしておく。

VIOUT は G2 に繋がない。このツールに電流 ADC は無い。`CURRENT MONITOR: NOT CONNECTED` と出る。Protection Board という名前だけでは、遮断できるとは扱わない。

## エンコーダ

センサーは 6 ピン。赤が +5V、黒が 2 本とも GND、白と緑が直交信号、残りの 1 本は開放。

レベル変換は秋月 AE-LCNV4-MOSFET（BSS138、113837）。TXS0104E ではない。各側に 10kΩ のプルアップがある。Core の内部プルアップとプルダウンは使わない。

| センサー | 変換基板 | Core |
| --- | --- | --- |
| 白 | HV1 → LV1 | Port C 黄 G17 |
| 緑 | HV2 → LV2 | Port C 白 G18 |
| 赤 +5V | HV | センサー側の 5V。Core の信号端子には入れない |
| GND | GND | Core GND |

変換基板の LV は Core の 3.3V。これは絶縁ではない。センサーの 5V と Grove の 5V を、確認なしで並列にしない。

5V の信号を Core の GPIO に直接入れない。

センサー GND とモーター GND は、既存の Protection Board で既につながっている。モーターの負荷電流を、細い信号 GND に流さない。

停止位置で、緑が約 5V、白が約 100mV だった測定が 1 回ある。位置が変われば値も変わる。毎回そうなる規則ではない。

G17 を A、G18 を B とする。SIGN が +1 のとき、B が Low で A が立ち上がる向きを正とする。機械と逆なら、DISARMED のあいだだけ `SET ENCODER_SIGN -1` とする。この対応は配線表と照合できるようにしてあり、分解能の確定値ではない。

## このソフトが止められないもの

画面の ESTOP と USB の `ESTOP` は、PWM を 0 にし、ブレーキ解除と主電源の指令を落とすソフトのラッチである。物理の非常停止ではない。無人、機構を支えた状態、周囲を隔離した状態で使う。負荷を保持する制御でもない。
