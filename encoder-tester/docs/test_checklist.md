## 始める前

- 他の軸が動けないようにしてある。
- 無人で、機構は支持され、周囲は隔離されている。
- 物理の非常停止に手が届く。画面と USB の ESTOP は、その代わりではない。
- 電流監視は接続されていない。
- G2 は全軸の AC 給電になり得る。CoreS3 は 1 台だけである。
- 上限は `SET` で入れる。未設定のままでは ARM できない。数値の範囲は入力検査であり、開始 Duty の推奨ではない。
- 以前「50〜60 で端に当たった」という話を、開始 Duty に使わない。
- 出荷済み制御の `RELAY_SETTLE_MS=100` は、測った電源待ち時間ではない。`POWER_SETTLE_MS` は別途測って入れる。

## 手順

- [ ] 24V の負荷を外した状態で、G2 主電源（XH 2pin #2）と G13 ブレーキ（XH 8pin #5、Base15 内 MOSFET の先）の極性と、起動時の出力を見る。G13 は CoreS3 内部で I2S_DOUT と共用なので、起動中に MOSFET が入らないことも見る。AC 側の露出した活線作業はしない。
- [ ] エンコーダの LV 側が 3.3V の範囲か、静止時の入力と PCNT の初期化を見る。
- [ ] PWM、DIR、周波数、分解能、指令の単位を、既存の `moter-controler` と照合する。正方向は DIR Low。100% は PWM 1023。
- [ ] 運転時間、最大 Duty、相対カウント、待ち、停止タイムアウトを `SET` する。相対カウントは物理限界の保証ではない。
- [ ] 主電源指令、ブレーキ解除指令、PWM 0 の準備まで進む。画面は指令であり、電圧の確認結果ではない。
- [ ] 操作者が決めた低い Duty と短い時間で 1 回だけ動かし、DIR、PWM、カウント、count/s を記録する。動かなくても Duty は自動で上がらない。
- [ ] 停止の列が最後まで進む。逆方向は、止まったあとの別の試験にする。運転中に DIR は反転しない。
- [ ] PWM の向きとカウントの向き、停止後のカウント、繰り返しを見る。
- [ ] 出力軸に外部の目印を置けるときだけ、動力で動かす前後の角度を別に測り、`CAL ANGLE` か `CAL REVS` に入れる。手では回さない。
- [ ] 角度が測れなければ、駆動応答として保存し、分解能は未確定のままにする。
- [ ] USB 断、タッチを離す、運転期限、停止、PCNT 異常を、無負荷か低いエネルギーから順に見る。

エンコーダ断線の確認で、無制限に動かさない。まず 24V を外し、出力指令だけを見る。

## 目視 1 回転

目視 1 回転は、自動で 1 回転して止まるモードではない。

- [ ] DISARMED で、停止とカウント安定を確認してから基準を記録する。
- [ ] ジョグは押しているあいだだけ。記録の操作で、安全側の期限や移動量の上限はリセットされない。
- [ ] 同じ目印が戻ったあと、同じ条件で完了を記録する。PCNT はゼロに戻さない。
- [ ] 方向ごとに 3 回以上を推奨。画面は各回と、有効な記録だけの平均、最小、最大、ばらつきを出す。
- [ ] 無効な記録も残す。方法の違う記録は混ぜない。
- [ ] シャフト名が `encoder` のときだけ PPR を count/rev の 4 分の 1 として表示する。それ以外は PPR UNKNOWN。公称分解能とは書かない。

## 記録の見方

CSV の GPIO 列はピンのレベルであり、リレー接点が閉じた証拠ではない。`count_total_x4` は符号付きの累積であり、ZERO DISPLAY の表示値ではない。PWM を切ったあとの惰性は、試験記録の coast と、`EVT trial_done` で分ける。
