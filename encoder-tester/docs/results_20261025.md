# フィードバックセンサー調査結果（2026-10-25）

対象: DOF Reality H3 のモーター #1（正面から見て右手前）。CoreS3 SE + encoder-tester、USB のみ給電（`env:m5stack-cores3-usbpower`）、H3 主電源 AC は入れたまま、主電源リレーとブレーキは G2 / G1 で入切。SET 値は [set_proposal.md](set_proposal.md)。生ログは `logs/session_*_20261025_*.{log,csv}`、要約は `runs/session_*_20261025_*.md`。

## 結論

| 項目 | 結果 |
| --- | --- |
| 信号形式 | 白・緑は 2 相の直交（A/B）インクリメンタル出力。駆動中に両相がトグルし、PCNT の 4 逓倍計数が滑らかに進む |
| 分解能 | **モーター軸 1 回転 ≈ 400 カウント（4 逓倍）**。実測 3 回転 = 1208 カウント（402.7/周）、3.75 回転 = 1494 カウント（398.4/周）。読み取り誤差込みで 400 ± 4。センサーが印を付けた軸と同じ回転子に直結していれば 100 PPR に相当するが、センサー内部の歯車の有無は未確認なので PPR は確定値ではない |
| 計数している軸 | モーター本体の軸（減速機の前）。減速比は未測定なので、出力軸（クランク）やシート角度あたりのカウントは未確定 |
| 符号 | `ENCODER_SIGN=1` のとき、positive（DIR Low）でカウントは**負**、negative（DIR High）で**正**。negative でシートが上がる（右手前が持ち上がる）、positive で沈む |
| 回転方向 | モーター軸を軸側から見て、negative で反時計回り（目視） |
| 静止時 | GND 接続後の DISARMED 基準（各セッション 3〜5 s）で変化 0。GND 接続後に ARM のみ（主電源 ON → ブレーキ解除 → READY 3 s → 停止 → ブレーキ → 主電源 OFF）を 2 回行い（18:52、18:53）、5 ms TRACE を含めて全区間 count 0。17:27 の 20 s 基準と 17:28 / 17:29 の ARM 2 回は GND 未接続で無効 |
| 必要なレベル変換 | AE-LCNV4-MOSFET（BSS138、10kΩ プルアップ）で 5V → 3.3V。この構成で計数に欠けは見られない（最大 約 1700 count/s まで確認） |
| GND | CoreS3 と H3 側の GND 共通が無いと、リレーもセンサーも反応しない（本日の最初の 4 回で再現）。GND は給電ケーブルと別に恒久配線する |

## 駆動応答（15 %、同一セッション、4 逓倍カウント）

| 条件 | 停止差分 | 定常 count/s | モーター軸回転数（400/周換算） |
| --- | --- | --- | --- |
| 10 % positive 400 ms | −250 | 約 −620 | 約 1.5 rev/s（約 95 rpm） |
| 10 % negative 400 ms | +147 | 約 +400 | 約 1.0 rev/s（約 60 rpm） |
| 15 % positive 250 ms ×3 | −426, −425, −448 | 約 −1700 | 約 4.2 rev/s（約 255 rpm） |
| 15 % negative 400 ms ×4 | +372, +372, +375, +372 | 約 +1000 | 約 2.5 rev/s（約 150 rpm） |

- positive（沈む向き）は negative（持ち上げる向き）の約 1.7 倍速い。重力負荷の差。
- 惰性（PWM 0 からブレーキ作動まで）は常に負方向で −1〜−45。1 回だけ −91（16 回目、シートが高い位置）。
- ブレーキ作動の瞬間の変化（駆動あり）は 0〜−25 が大半。例外として +76 が 1 回（10 % positive）、+10 が 1 回。PWM 無しのリレー切替だけ（ARM のみ ×2、GND 接続後）では変化 0 で、10/22 の −260 と同じ条件では再現しなかった。
- 15 % negative 400 ms の停止差分が 4 回とも 372〜375 で、同条件の再現性は 1 % 以内。
- 計数の欠けが無いことの裏付け（印の位置とカウントが合う）は両方向で取れている。negative は約 1000 count/s で 3 周 = 1208 が基準に戻った。positive は約 1700 count/s の戻し駆動 3 回（計 −1198）のあと、累計 +296 の予測 3 時 10 分に対して目視 3 時（差 10° 以内）。

## 使い方（実装への含意）

- GPIO17 = A（白）、GPIO18 = B（緑）。PCNT 2 チャネル、エッジ＋レベルで 4 逓倍、内部プル無し、glitch filter 無しで問題なし。
- ファーム: encoder-tester `env:m5stack-cores3-usbpower`、pioarduino 55.03.312、Arduino-ESP32 3.3.12、ESP-IDF 5.5.5、M5Unified 0.2.26、M5GFX 0.2.33。
- 位置の単位はまず「モーター軸カウント（400/周）」で持つ。シート角度への換算は減速比か外部角度の測定を待つ。
- 停止判定: 100 ms 窓の count/s が 20 以下を 200 ms 継続、で安定して確認できた（stop_timeout FAULT は 0 回）。
- 無パルス停止（START_GRACE_MS）は 100〜200 ms で実用になる。本日は GND 欠落時に 4 回とも正しく働いた。
- 過速度上限は、25 % で約 3000 count/s。100 % に外挿すると 1 万 count/s を大きく超えるので、`MAX_COUNT_PER_S=10000` は低すぎた。実測を Duty ごとに積み上げて決める。
- ブレーキ解除で PWM 0 のとき、負荷側へじわじわ流れる。位置保持は PWM かブレーキのどちらかで必ず行う。

## 未確定・次の測定

1. **角度換算**。高さ対カウントは 4 点で取れた。シート角度にするには回転中心までの距離（または水準器での角度差）が要る。減速比はクランクに印を付けて測れるが、1 周できるかは現地判断。
2. ~~可動範囲の両端~~ 測定済み（上の表）。着座荷重での中立位置と、端に当てたときの電流は未測定。
3. 25 % まで計数欠け無しを確認済み。それ以上の Duty での確認と、レベル変換の立ち上がり、PCNT の glitch filter の要否。
4. ブレーキ作動時の +76 / 10/22 の −260 の原因（実移動か電気ノイズか）。
5. 電源断（GitHub Issue #1）。DIN 12V と USB の同時接続で約 85 秒後に落ちる。本日の測定は USB のみで回避。
6. 10/22 の `a=0 b=0` と本日の `a=1 b=1`（GND 欠落時）/ 停止位置により変わる値の整理。センサー出力段（プッシュプルかオープンコレクタか）は未確認。
